
🔐 Login/Signup Module
1. Valid Login
Description: Verify the user is able to log in with valid credentials.

Expected Result: User is redirected to the home page/feed.

2. Invalid Login
Description: Check login with incorrect password or username.

Expected Result: Error message like “Incorrect username or password” should be displayed.

3. Empty Fields
Description: Try logging in without entering any credentials.

Expected Result: Appropriate validation messages should be shown.

4. Forgot Password
Description: Click on “Forgot Password” and follow the reset flow.

Expected Result: Password reset email/SMS should be sent to the registered user.

📸 Post (Image/Video Upload) Module
1. Upload Image
Description: Upload an image from gallery or camera.

Expected Result: Image should be uploaded and visible in user’s profile/feed.

2. Upload Video
Description: Upload a video with a caption.

Expected Result: Video should play correctly after upload.

3. Add Filters/Tags/Location
Description: Apply a filter, tag people, and add a location.

Expected Result: All metadata should be saved and displayed correctly.

4. Invalid File Format
Description: Try uploading unsupported formats like .exe, .zip, etc.

Expected Result: Error message like “Unsupported file type” should appear.

🏠 Home/Feed Page
1. View Posts
Description: Scroll through the feed and verify post visibility.

Expected Result: Posts from followed users should appear in chronological or algorithmic order.

2. Like/Unlike Post
Description: Tap the like button or double-tap to like/unlike.

Expected Result: Like count should increase/decrease accordingly.

3. Comment on Post
Description: Post a valid comment.

Expected Result: Comment should appear under the post instantly.

🔍 Search Module
1. Search User
Description: Search a username from the search bar.

Expected Result: Matching user profiles should appear in results.

2. Search Hashtag
Description: Search by a hashtag.

Expected Result: Posts with that hashtag should appear in grid view.

3. Search Invalid User
Description: Enter random characters or a non-existing username.

Expected Result: “No results found” message should appear.

👤 Profile Module
1. Edit Profile
Description: Update profile details like name, bio, website.

Expected Result: Changes should be saved and reflected.

2. Change Profile Picture
Description: Upload a new profile image.

Expected Result: Image should be updated and visible.

3. Private Account Toggle
Description: Turn on/off the private account setting.

Expected Result: Account visibility should change accordingly.

🔔 Notifications
1. Receive Notification for Like/Comment
Description: Check if user receives a notification when someone likes/comments.

Expected Result: Notification should appear in the notification tab.

📩 Direct Messaging (DM)
1. Send Message
Description: Send a message to another user.

Expected Result: Message should be delivered and visible in the chat window.

2. Receive Message Notification
Description: Check for real-time message notification.

Expected Result: Notification should appear when a new message is received.

🎥 Stories & Reels
1. View Story
Description: Tap to view another user’s story.

Expected Result: Story should open and auto-play.

2. Post Story
Description: Upload a photo/video to story.

Expected Result: Story should be visible for 24 hours.

3. Upload Reel
Description: Create/upload a short reel with effects and music.

Expected Result: Reel should be posted and viewable.

⚙️ Settings
1. Logout
Description: Tap on logout from settings.

Expected Result: User should be redirected to the login page.

2. Block/Unblock User
Description: Block a user from profile options.

Expected Result: Blocked user can no longer view your content.
